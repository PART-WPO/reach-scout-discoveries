# REACH Scout Preprint Watchlist — first of each month

Track preprints via Crossref posted-content and DataCite explicit preprint metadata, and retain previously verified preprint leads. Recheck the tracked preprint on the **1st of each month**, including weekends, using the existing free GitHub Actions infrastructure. The regular hourly Scout missions remain weekday-only.

A preprint DOI is ineligible for the new-output Discovery Hub workflow. Treat online-first journal versions of record as published even if print comes later; continue to use the established Crossref print-preferred publication-date policy. Crossref created dates and preprint posted dates never prove journal publication.

Only an explicit isPreprintOf (or DataCite IsPreprintOf) DOI relationship plus a verified Crossref journal-article with real published/issued metadata creates a final-article DOI *research lead*. A plausible title match alone is not proof. Preserve the preprint original, checked-source evidence and any metadata outages; neither a preprint nor a linked final DOI is automatically staged. Final journal DOI requires complete REACH and Scout duplicate/version screening, verified specific WPO funding/project and required metadata, then the existing human review process.

Independent DOI-seeded related-output research remains eligible even when the preprint is on hold. Do not rewrite immutable source batches, existing reviewer decisions, or source DOI identities. Public GitHub metadata must never contain private reviewer details.
