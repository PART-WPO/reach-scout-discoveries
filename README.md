# REACH Scout Discoveries

Staging area for **unreviewed public research-output findings** from the REACH Scout daily research sprints.

The `main` branch contains only findings intentionally merged after human review. Discovery Hub reads the validated `manifest.json` and dated batches; it does not automatically approve any output or add it to REACH.

Never publish personal data, protected NOAA/Smartsheet information, authentication tokens, or private reviewer decisions here.
